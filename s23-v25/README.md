# S23 v25

Tested and deployed on NeoForge 1.21.1.

- Create Depot charging through a powered vertical shaft: 60-minute charge, 30-minute base riding duration.
- Command-block smithing grants unlimited battery. Unbreaking extends duration; Mending consumes rider XP to recharge.
- Nether heat throttles scooters to 20 km/h; cooling and pickup persistence supported.
- Read-only NBT access and cached enchantment lookup reduce repeated cloning and registry work. The reported long server freezes are still under investigation. Chams now shade only a conservative projected region: a 3840x2160 eight-highlight GPU comparison reduced 7.29 ms to 0.81 ms (89 percent), with byte-identical framebuffer output. This is a pass benchmark, not an overall FPS guarantee.
- Anvil names: jeb_ cycles rainbow accents; Dinnerbone flips the scooter and gravity, with lethal sun exposure at build height.
- Rentals explode in the Nether like beds.

Dedicated server/client regression and activation rollback passed. Visual sun-death confirmation remains pending. Server and AutoModpack SHA256 and public archive checks verified; credentials, player data and music library excluded.
