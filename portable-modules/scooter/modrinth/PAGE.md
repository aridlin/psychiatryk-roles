# Portable Scooters

Ride, upgrade and customize an electric scooter with responsive steering, storage, music and configurable handling.

## Ride

Place the scooter, right-click to mount, and use W to accelerate. S brakes before reversing. A/D steer; hold Ctrl for deliberate drifting. Space jumps, with stronger jumps when wind charges are in your hotbar. Firework rockets provide a temporary boost. Press E while riding to open storage, settings and help.

## Craft

The standalone mod keeps the original recipe:

| | | |
|---|---|---|
| Empty | Iron ingot | Empty |
| Black wool | Redstone | Black wool |
| Copper ingot | Iron ingot | Copper ingot |

The Goplanska Better MC addon applies its own endgame recipe. That restriction is not part of this standalone download.

## Customize

Smithing upgrades add storage, a passenger seat, music and other features. Paint with dyes, apply armor trims and supported enchantments, or bind a scooter for owner protection and recall. The mod includes rental variants, which have conservative defaults and do not spawn globally unless the server enables them.

Park to charge with coal. Optional Create charging integration can use a powered kinetic block beside a depot. Handling and safety settings are configurable; an admin settings screen exposes supported riding values.

## Install

Minecraft **1.21.1**, **NeoForge 21.1.248 or newer in the 21.1 series**, and **Java 21**. Install on both the server and each client. No other mod is required.

The model uses Minecraft's ordinary entity rendering buffers. The download includes an original lightweight primitive model, not the private server's imported model or its rental logos.

Do not install this beside the older merged Psychiatryk Roles mod containing `goplanska_kukirin`; they register the same item and entity IDs.

## Optional features

Real terrain headlights require a separately packaged compatible dynamic-light adapter. Extra JEI descriptions and Spears compatibility adapters are preserved as source but are not claimed as installed dependencies of this core release. A separate highlighting API can display owner markers and chams when a server integration supplies permitted targets.
