# Consultant spyglass preset candidate

`/konsultant-item presets` and tab completion omitted `spyglass`. Giving an ordinary spyglass instead also failed for a Konsultant because the role's generic right-click restriction canceled use. This overlay adds a tagged vanilla spyglass preset, keeps the existing expiry and protected-equipment behavior, and lets that specific item zoom when used in air or while pointing at a block. An untagged spyglass does not gain the exception.

`build.py` requires the exact verified live 3.0.12 JAR (SHA-256 `6fbde292e6e88a0fa250966203c173ca06ebf77b36d1530eab4de82763f12566`) and the existing Java 21 SDK classpath file. It changes exactly `CustomPresets.class`, `PsychiatrykRoles.class`, and the six metadata versions to `3.0.13-bmc5`. It refuses a different input, missing dependencies, unexpected class outputs, duplicate/corrupt ZIP entries, or any extra JAR change. The original 3.0.12 installer and live server are untouched by this build.

The isolated test mod `SpyglassCheck.java` checks the command preset list, the resulting vanilla item and consultant tag, timed expiry, untagged-item exclusion, and NeoForge air/block interaction events. `supervise_spyglass.py` starts a separate loopback-only full-pack dedicated server on the user's CachyOS QA machine with a 3 GiB heap, 6.5 GB address-space limit, available-memory guard, 600-second deadline, and clean stop. The helper JAR is test-only and must not be included in a public installer or production server.

The corrected candidate JAR is SHA-256 `58968efafbfb46a3d929b5fe2ebbf3baacd495fe5c94802448483d4bcf01014c`. ASM verification passed for both changed classes. In the isolated 299-JAR full-pack server, the initial test-helper package collided with the Roles module; moving that helper into its own package resolved the fixture error. The first functional run then exposed that the live 3.0.12 Roles class never connected `CustomPresets` to the command. The corrected patch adds only `spyglass` to the command list and routes only that preset to the helper. Its final full-pack run reached `Done (10.661s)`, printed `SPYGLASS_CHECK PASS list + vanilla item + consultant tag + expiry + air/block use`, and saved all dimensions on a clean exit. The final run's status is in the ignored `build/remote-status.json` and the source test is `SpyglassCheck.java`.

This candidate is **not deployed**. A real client zoom test and client/server version-sync check are required before distribution. The change modifies native client interaction code, so the current 3.0.12 client cannot be assumed compatible with a server-only rollout.
