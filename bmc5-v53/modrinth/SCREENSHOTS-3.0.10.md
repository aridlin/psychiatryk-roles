# Modrinth gallery shot list for Psychiatryk 3.0.10

No image has been uploaded to the existing project. Capture these from the
final, matching client and server, after a real world join. Use the **aridlin**
account and its real skin in feature shots; make the name legible in a genuine
game UI (for example the player list) or place a second player's camera so
the aridlin nametag and skin are visible together. Do not paste a name or skin
onto another player's screenshot. Hide server secrets, coordinates, private
chat, debug overlays and other players' identities unless they consent.

Suggested sequence, 16:9 at native resolution:

1. **Hero / Peeb + KuKirin:** aridlin in a recognizable in-game setting with
   Peeb grappling or a parked/ridden scooter, with the character and name
   identifiable. Use one actual game frame, no generated composite.
2. **Peeb grapple:** a clear side view of the tether, anchor and character in
   motion. Capture a second frame if the reel requires showing momentum.
3. **Scooter:** aridlin riding the KuKirin, side enough to see the model;
   optionally a separate frame of its real upgrade/storage menu.
4. **Void Door pair:** opened door/frame with the portal plane visible; if
   cross-dimension travel is illustrated, caption the two real frames rather
   than fabricating a single combined world image.
5. **Poker and music:** capture each actual interface in a playable state,
   with legible controls and no unrelated modal. These can be gallery images
   after in-game UI QA confirms the intended blur behaviour.
6. **3.0.10 runtime:** join progress timeline during a cold asset preload,
   then a cache-hit reconnect if useful. Capture the displayed phase and
   matching version, not just the loading splash. A decorative variant or
   HUD scene can be shown separately once it exists on the live test server.

Before upload: verify each file's build provenance/date, aspect ratio, no
blurred custom screen, no private data, and that the depicted feature works
in the released JAR. Name files descriptively; write literal captions such
as `Peeb's grapple on the 3.0.10 client` rather than performance claims.
Choose the strongest actual gameplay frame as the featured gallery image.
