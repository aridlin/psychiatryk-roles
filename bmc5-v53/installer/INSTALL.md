## English

1. Prism: Add instance → Import → choose the .mrpack or .zip.
   CurseForge: Create a profile → Import → choose the .zip.
2. Use Java 21 and your signed-in Minecraft account. Launch this instance.
3. Multiplayer → Goplanska — Better MC5 (goplanska.pl).
4. AutoModpack downloads the server-selected pack. Compare the first-connection
   fingerprint with the value above before accepting it.
5. Finish downloading and accept the required relaunch. Rejoin afterwards.
   Keep using this same instance for later updates.

This first-run installer pins Minecraft 1.21.1 / NeoForge 21.1.250 / AutoModpack4.0.6.
The full server pack downloads on connection; this is not an offline full-pack ZIP.
The archive contains no third-party mod binaries, private credentials or player data.
AutoModpack is resolved from its original publisher by your launcher.
Official AutoModpack: https://modrinth.com/mod/automodpack/version/e6HhD1Ik
Help / exact custom recipes: https://info.goplanska.pl/
