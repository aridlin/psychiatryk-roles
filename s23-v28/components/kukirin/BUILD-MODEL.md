# Active scooter model

The active `kukirin_g2.glb` and `kukirin_g2.mesh` are an original G2-style game model, generated by `build_clean_g2.py`. The model has complete rigid assemblies, not triangle regions cut out of a fused print mesh. Code and active geometry use GPL-3.0-or-later.

Generate using Python with `requirements.txt` installed:

```
python work/kukirin/export_g2_glb.py
python work/kukirin/build.py
python work/roles-unified/build.py
```

GemRender 0.1.6 is required on clients. Its source is bundled in `licenses/gemrender-source.zip`; upstream is https://github.com/Warfactory-Official/GemRender. Extract it to `work/model-render-research/GemRender`, use Java 21, and build with `./gradlew :1.21.1:jar`. The game renderer uses Flywheel visuals when available and GemRender's direct GPU path with Flywheel disabled. The small mesh renderer supplies the custom chams mask passes.

The archived Thingiverse STL and its CC BY-SA 4.0 attribution remain available separately in `LICENSE-KUKIRIN-MODEL.txt`. It is not the active game geometry. `repair_g2_model.py` and `convert_g2_model.py` document the retired print-model experiment.
